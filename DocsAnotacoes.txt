Terraform CLI:

     Comandos:

        terraform init: 

            Comando básico para inicializar o projeto, baixar os providers e módulos necessários (se houver alterações tmb), criar o arquivo de estado local e o diretório .terraform. 
            (após rodar o init e as validações rodar o arquivo com as credênciais).

        Terraform FMT:

            terraform fmt -check: Esse comando verifica se o código está formatado corretamente, e diz qual arquivo pode ser alterado

            terraform fmt -diff: Mostra a diferença entre o código atual e o código formatado, alterando o código.

            terraform fmt: Altera os arquivos que estão com formatação "errada".

            terraform validate: valida se o código está correto, sem erros de sintaxe.


        Terraform Plan:

            terraform plan: é responsavel por mostrar o que será criado, alterado ou destruído, sem aplicar as alterações.

            terraform plan -out plan.out: exporta um arquivo com o plan.

            terraform show plan.out: O arquivo é binario, o show serve para abrir ele.

        Terraform Apply:

            terraform apply: Faz a valisação do plano e pede confirmação para aplicar as mudanças.

            terraform apply -destroy (ou usar só terraform destroy): Destroi o bucket criado.

            terraform apply plan.out: Formatado recomendado de realizar um apply é usar de base o plan.out criado com o terraform plan.

        Export Variaveis:

            Export TF_VAR_nomeVariavel=valorvariavel

            terraform plan -out plan.out -var nomeVariavel="valorVariavel"

            terraform plan -out plan.out -var-file=nomeArquivoComVariavel

        Terraform Output:

            Terraform Output retorna os outputs configurados no terraform.

            Terraform Output -raw nomeDoOutputDesejado retorna o output especifico. (Até mesmo sensiveis)
